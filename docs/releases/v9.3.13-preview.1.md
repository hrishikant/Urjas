# Urjas 9.3.13 Preview 1 - Native mobile redesign

iPhone preview, app version **9.3.13**, build **226**, requiring iOS 17 or later.
This is a separate prerelease; stable v9.3.11, `main` and the stable AltStore source
remain unchanged.

## New interface

- Three real-data rings: Sleep on the left, larger Recovery in the centre, and
  Strain on the right. Ring faces omit percentage symbols; Strain displays on
  0-21 without changing the stored scores.
- Today, Activity, Sleep, Health and searchable More, with all 26 original More
  destinations and 50 destinations in total.
- Light and dark themes, readable solid cards, larger-text support and native
  controls for the existing workout, sleep, journal, provider and layout tools.
- Settings > Appearance > New mobile design can restore the previous interface.
  Previous layout, sky, transparency and score-scale preferences are retained.
- Health detail links retain the displayed reading's source. Widget and expanded
  Live Activity Strain values follow the new display scale while retaining raw
  values and compatibility with older activity payloads.

## Existing features retained

Custom automatic workout starts and stops, historical workout detection, sport
review and prediction, raw-IMU refinement, manual recordings, imported history,
sleep edits and naps, Coach consent, backups and Live Activities remain native.
The redesign does not change database schemas, scoring formulas or Bluetooth
protocol logic. It also includes the selected upstream improvements and UI fixes
from the two 9.3.12 previews.

## Preview coverage and limits

The iOS app and shared macOS regression bundle compile. The 172 targeted app
regressions and 41 design-package tests passed. Simulator walkthroughs covered all
50 destinations, both themes, compact phones and larger text, score navigation,
the full sport picker and recording-end confirmation, manual workout persistence,
sleep and nap editor cancellation, Coach setup, saved layout preferences and the
previous interface. Live Activity payload compatibility is covered separately.

Synthetic data was used only in the DEBUG simulator harness. This Release IPA
does not include that seeding harness.

Bluetooth behaviour, real-band measurements, background execution, HealthKit
permissions, wrist cues and system Live Activity delivery still require checks
on your iPhone and band. Existing iOS background limits continue to apply.

## Install without deleting your history

1. Export a backup from the currently installed app first.
2. Install this IPA over your existing Urjas using the same sideloader, Apple ID
   and signing/bundle-ID setup. **Do not uninstall the existing app.**
3. Keep the widget extension enabled when re-signing. It supplies Home/Lock Screen
   widgets and the Live Activity renderer.

The original `com.noopapp.noop` identity and app/widget capability requests are
retained. As in the previous iPhone preview, the embedded watch app is omitted.
The IPA carries a replaceable ad-hoc capability template, not an Apple
distribution signature; AltStore, SideStore or Sideloadly must re-sign it for your
phone.
